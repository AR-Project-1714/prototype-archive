      Tips Pemecahan Masalah:

      1. Pastikan Anda memiliki koneksi internet aktif karena aplikasi ini mengunduh library React/Babel dari CDN.

      2. Periksa apakah CDN unpkg.com atau jsdelivr.net diblokir oleh jaringan/firewall/VPN/adblocker Anda.

      3. Buka Console Developer Tools (tekan F12 atau klik kanan -> Inspeksi -> pilih tab Console) untuk melihat log lengkap.

      4. Coba muat ulang halaman dengan menekan Ctrl + F5 (Force Reload).
